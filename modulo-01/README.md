# 🐍 Python Fundamentals - Módulo 01

Repositório dedicado ao estudo da sintaxe, tipos de variáveis e estruturas básicas da linguagem Python. Este módulo reúne anotações práticas e os primeiros scripts desenvolvidos para consolidação do aprendizado.

---

## 📂 Estrutura do Módulo

O módulo está organizado em conceitos fundamentais e um projeto prático para aplicação do conteúdo:

### 🧩 Tipos de Variáveis (`/tipos_variaveis`)
Arquivos focados na exploração e manipulação dos tipos de dados nativos do Python:
* **`booleanos.py`**: Estudos sobre lógica booleana (`True` / `False`) e operadores lógicos.
* **`numeros.py`**: Operações matemáticas básicas, tipos `int` (inteiros) e `float` (ponto flutuante).
* **`textos.py`**: Manipulação de strings, concatenação e métodos nativos de texto.
* **`variaveis.py` & `tipos_de_variaveis.py`**: Conceitos de atribuição, tipagem dinâmica e convenções de nomenclatura.

### 📚 Estruturas de Dados (`/tipos_variaveis` & Raiz)
Práticas com coleções e agrupamentos de dados:
* **`listas.py`**: Listas mutáveis, indexação e métodos como `append`, `pop` e `sort`.
* **`tuplas.py`**: Estruturas imutáveis e casos de uso específicos.
* **`dicionarios.py`**: Estruturas de chave-valor e métodos de busca/manipulação.

### ⚙️ Execução e Modularização
* **`meu_primeiro_ola.py`**: O clássico "Olá, Mundo!" para validação do ambiente de desenvolvimento.
* **`modulos.py`**: Primeiros passos na importação e reutilização de códigos e bibliotecas.

### 🚀 Projeto Prático (`/projeto`)
* **`gerenciador_de_tarefas.py`**: Um aplicativo em linha de comando (CLI) que aplica de forma integrada os conceitos de variáveis, estruturas de dados (listas/dicionários) e controle de fluxo estudados ao longo do módulo.

---

## 🛠️ Como Executar os Exemplos

1. Certifique-se de ter o **Python 3.x** instalado em sua máquina.
2. Abra o terminal na pasta do arquivo que deseja testar.
3. Execute o comando:
   ```bash
   python nome_do_arquivo.py
   ```
